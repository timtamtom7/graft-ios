# Graft

A practice and assignment tracker with a teacher view.

## What it does

- Practice plans
- assignments
- student/teacher views
- achievements

## Targets

- iOS with Mac and widget companions

## Structure

Key types:

- ``PracticePlanView``
- ``StudentAssignmentsView``
- ``TeacherView``
- ``SocialService``
- ``DatabaseService``
- ``AchievementService``
- ``WidgetDataManager``

The `TeacherView` is unusual in this batch — most of these are single-user tools.

## Status

Apple-platform experiment built to explore what an AI coding agent could produce for a native app. Not actively maintained.
